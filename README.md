# kickstart-sd.nvim
Personal customizations to kickstart.nvim kept isolated in this repository
for easier merges from upstream.

Parent repository: https://github.com/sdebnath/kickstart.nvim

## Development
When cloned recursively as part of the parent kickstart repository, the
default remote URL will consist of the publicly available HTTP endpoint. To
make and push up changes, change the remote URL using:

```
git config remote.origin.url git@github.com:sdebnath/kickstart-sd.nvim.git
```
